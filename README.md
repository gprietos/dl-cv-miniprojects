# Deep Learning for Computer Vision Mini Projects

This repository contains small, focused projects that explore core concepts in deep learning applied to computer vision.

This repository is intended for learning and experimentation only.


## Overview

Each mini project is designed to be self-contained and demonstrates one or more techniques commonly used in modern computer vision workflows:

- Image classification
    - ResNet
- Object detection
    - YOLO

## Structure

The repository is organized into separate project folders, each with its own dataset handling, model definition, and training scripts.

Example structure:

- `image-classification/resnet/`
- `object-detection/yolo/`


## Getting Started

 Install dependencies:

   ```bash
   uv pip install -r requirements.txt
   ```


## Common Concepts

- Data preprocessing and augmentation
- Convolutional neural networks (CNNs)
- Residual Networks (ResNet)
- Metrics such as accuracy, precision, recall, IoU
- Fine tuning on pretrained backbones
- Loss functions for classification
